Security & session

Admin sessions automatically log out after 3 minutes without activity. The administrator password is set as a visible in the public JavaScript configuration. Do not use this for real payment operations.

For security, do not store bank credentials, gift-card redemption codes, passwords, or other highly sensitive payment secrets in a public client-side file. Share only the payment destination details members need to complete a transaction.
